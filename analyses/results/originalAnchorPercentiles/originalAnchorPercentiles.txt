Original event-years: subjective anchors as percentiles of the no-anchor distribution
====================================================================================

Purpose: for each original (subjectively chosen) low/high anchor, report where that
value falls in the empirical distribution of no-anchor estimates for the same question.
This answers the R2 reviewer request to compare subjective anchors to percentile-based
anchors (e.g., Barrera Experiment 2 used 5% and 95%; F2026 replication used 1st/99th).

Data: data/anchorYearsDecontaminatedLong.csv
No-anchor cohort: version == 3 (after contaminant removal).
Anchor values: original Low/High from manuscript Table 1.

Percentile definitions:
  midrank_pct = 100 * (#estimates < anchor + 0.5 * #estimates == anchor) / n
  cdf_pct     = 100 * (#estimates <= anchor) / n
Primary reported value is midrank_pct (standard percentile rank).

Note: Firefox truth in the long CSV is [2002.0]; manuscript uses 2004.
      Percentiles below use estimates only (truth not needed).

Interpretation notes
--------------------
- A Low% near 5 and High% near 95 would resemble Barrera Experiment 2 anchor placement.
- A Low% near 1 and High% near 99 would resemble the F2026 replication anchor rule.
- Subjective original anchors are often well inside the no-anchor range (not as extreme
  as 1st/99th), especially on the high side for recent events.
